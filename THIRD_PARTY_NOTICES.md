# Third-party notices

The Mac app uses no third-party code.

The Android app includes these open source libraries, each under the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0):

- **ZXing Android Embedded** (journeyapps) — scans the pairing QR code
- **ZXing** (zxing authors) — QR code decoding
- **AndroidX** and **Jetpack Compose** (The Android Open Source Project) — app framework and screens
- **Kotlin standard library** and **kotlinx.coroutines** (JetBrains) — language runtime

The narration in the demo videos was generated with
[Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) (Apache License 2.0). The
background music and sound effects were synthesized for this project.
